# W2-PM5 — Zenmap Based Network Scanning

## Objective

Perform and document an authorized network-scanning exercise using Zenmap as part of the Networkwalks B083C Week 2 cybersecurity internship.

## Lab Network

| Item | Value |
|---|---|
| Local Wi-Fi IPv4 address | `192.168.1.242` |
| Subnet mask | `255.255.255.0` |
| Local network | `192.168.1.0/24` |
| Default gateway | `192.168.1.1` |

## Methodology

1. Identified the local IPv4 address and subnet information for the authorized lab network.
2. Determined the local network range as `192.168.1.0/24`.
3. Opened Zenmap and configured the scan against the authorized lab network/hosts.
4. Executed the network scan.
5. Reviewed the discovered hosts and the port/service information reported by Zenmap.
6. Captured the scan results as evidence for the Week 2 project.

## Results

The Zenmap practical was completed successfully.

The exact host, port, and service observations should be transcribed from the final Zenmap scan output and screenshots so the repository does not claim values that were not actually observed.

## Key Learning Outcomes

- Identified a local IPv4 network and CIDR range.
- Used Zenmap as a graphical interface for Nmap-based network scanning.
- Practised host discovery and network enumeration in an authorized environment.
- Learned to interpret discovered ports and services from scan output.
- Documented technical findings as cybersecurity evidence.

## Security & Ethical Considerations

Only scan systems and networks for which explicit authorization has been provided. Network scanning can generate traffic and may be detected or logged by security controls. The exercise was limited to the authorized educational/lab environment.
