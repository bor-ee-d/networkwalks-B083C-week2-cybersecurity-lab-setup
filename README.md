## W2-PM3 — Maltego Based Footprinting

### Objective

To gain practical experience with Maltego for authorized footprinting and information gathering.

### Work Completed

The Maltego practical exercise has been completed using the authorized target **`networkwalks.com`**.

The workflow included:

1. Using `networkwalks.com` as the starting domain.
2. Working with the **Email Address** entity.
3. Running the **To Emails @domain [Search Engine]** transform.
4. Successfully retrieving email-address entities in the Maltego graph.
5. Reviewing the returned relationships and results as part of the footprinting exercise.

### Evidence

Screenshots and supporting evidence will be added under:

`Maltego-Footprinting/screenshots/`

### Key Learning

The exercise focuses on understanding how information can be collected and represented through relationships between entities while keeping the activity within an authorized cybersecurity lab environment.
